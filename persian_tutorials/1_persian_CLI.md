# CLI (رابط خط فرمان - Command Line Interface)

## مقدمه

در سیستم‌عامل‌هایی مانند Windows و macOS معمولاً یک رابط گرافیکی به نام GUI
(Graphical User Interface) داریم.

GUI یک رابط بین کاربر و کامپیوتر است که به صورت گرافیکی کار می‌کند. کاربر
می‌تواند با کلیک کردن روی Desktop، فایل‌ها و پوشه‌ها را مشاهده کند، فایل‌ها
را باز کند، حذف کند و پوشه‌های جدید بسازد.

اما در CLI (Command Line Interface) به جای استفاده از محیط گرافیکی، با
نوشتن دستورها مستقیماً با سیستم‌عامل ارتباط برقرار می‌کنیم.

## چرا از CLI استفاده کنیم؟

دلایل مهم استفاده از CLI:

1.  بیشتر سرورها مبتنی بر Linux هستند و با CLI مدیریت می‌شوند.
2.  بسیاری از ابزارهای توسعه فقط نسخه خط فرمان دارند.
3.  برای کارهای حرفه‌ای توسعه نرم‌افزار، CLI سریع‌تر و قدرتمندتر است.

## باز کردن ترمینال

در مک:

    Command + Space → Terminal

در ویندوز:

    CMD یا PowerShell

ترمینال محیطی است که دستورها را در آن اجرا می‌کنیم.

## دستورات پایه

### pwd

نمایش مسیر فعلی:

``` bash
pwd
```

مثال:

``` bash
/Users/apm
```

### cd

تغییر مسیر:

``` bash
cd desktop
```

برای برگشتن یک پوشه به عقب:

``` bash
cd ..
```

### ls

نمایش فایل‌ها و پوشه‌های موجود:

``` bash
ls
```

### mkdir

ساخت پوشه جدید:

``` bash
mkdir new_folder
```

### touch

ساخت فایل خالی:

``` bash
touch l1.py
```

### vim

باز کردن یا ساخت فایل و نوشتن داخل آن:

``` bash
vim l1.py
```

در vim:

    i → شروع نوشتن
    ESC → خروج از حالت نوشتن
    :wq → ذخیره و خروج

### cat

نمایش محتوای فایل:

``` bash
cat l1.py
```

### rm

حذف فایل:

``` bash
rm l1.py
```

### rm -rf

حذف پوشه به همراه تمام محتویات:

``` bash
rm -rf folder1
```

## اجرای برنامه پایتون از ترمینال

نیازی نیست همیشه فایل Python را داخل IDE باز کنیم. می‌توانیم مستقیم از
ترمینال اجرا کنیم:

``` bash
python3 l1.py
```

مثال خروجی:

    salam
    40

## ساخت محیط مجازی Python

ساخت محیط مجازی:

``` bash
python3 -m venv fanavari
```

فعال کردن محیط:

در macOS و Linux:

``` bash
source fanavari/bin/activate
```

خروج از محیط:

``` bash
deactivate
```

## خلاصه دستورات

  دستور             کاربرد
  ----------------- ----------------------
  pwd               نمایش مسیر فعلی
  cd                رفتن به یک پوشه
  cd ..             برگشت به پوشه قبلی
  ls                نمایش محتویات پوشه
  mkdir             ساخت پوشه
  touch             ساخت فایل
  vim               ساخت و ویرایش فایل
  cat               نمایش محتوای فایل
  rm                حذف فایل
  rm -rf            حذف پوشه
  python3           اجرای فایل پایتون
  python3 -m venv   ساخت محیط مجازی
  activate          فعال کردن محیط مجازی
  deactivate        خروج از محیط مجازی
