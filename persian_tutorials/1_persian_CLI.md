# CLI (Command Line Interface)

# رابط خط فرمان (CLI)

در سیستم‌عامل‌هایی مثل **Windows** و **macOS** ما چیزی به نام **GUI
(Graphical User Interface)** داریم.

## GUI چیست؟

GUI یک رابط بین کاربر و کامپیوتر است که به شکل گرافیکی کار می‌کند.

یعنی شما با شکل‌ها، آیکون‌ها و پنجره‌ها با کامپیوتر ارتباط برقرار می‌کنید.

------------------------------------------------------------------------

## چرا وقتی GUI داریم از CLI استفاده کنیم؟

دلایل استفاده از CLI:

1.  بیشتر Server ها مبتنی بر Linux هستند و معمولاً با CLI مدیریت می‌شوند.

2.  بسیاری از ابزارها فقط در حالت CLI ساخته شده‌اند و از طریق خط فرمان
    اجرا می‌شوند.

------------------------------------------------------------------------

در GUI شما با کلیک کردن کار می‌کنید:

-   روی Desktop کلیک می‌کنید و لیست فایل‌ها را می‌بینید.
-   روی یک فایل کلیک می‌کنید تا باز شود.
-   فایل مورد نظر را حذف می‌کنید.
-   یک Folder جدید می‌سازید.
-   یک فایل جدید ایجاد می‌کنید.

اما در CLI همه این کارها را با نوشتن دستور انجام می‌دهیم.

------------------------------------------------------------------------

# Command Line Interface (CLI)

CLI یعنی یک محیط متنی که جلوی ما قرار دارد و ما با نوشتن دستورها با
کامپیوتر کار می‌کنیم.

معمولاً یک صفحه مشکی رنگ باز می‌شود و دستورات را در آن وارد می‌کنیم.

![cli_terminal](/tutorial_figs/terminal.png)

------------------------------------------------------------------------

# چرا Developer ها از CLI استفاده می‌کنند؟

اکثر Developer ها از CLI استفاده می‌کنند، نه GUI.

وقتی می‌گوییم یک Server گرفته‌ایم، یعنی یک کامپیوتر در اختیار ما قرار
گرفته است.

این کامپیوتر ممکن است:

-   در یک کشور دیگر باشد.
-   در یک شرکت باشد.
-   در یک دیتاسنتر باشد.
-   یک ماشین مجازی باشد.

برای مدیریت این سیستم‌ها باید CLI بلد باشیم تا بتوانیم به آن‌ها متصل شویم.

------------------------------------------------------------------------

# باز کردن Terminal

## Mac

برای باز کردن Terminal:

    Command + Space

را بزنید و Terminal را جستجو کنید.

## Windows

می‌توان از:

    CMD

یا:

    PowerShell

استفاده کرد.

# پیدا کردن مسیر فعلی

# ساخت Folder جدید

برای ساخت یک Folder جدید از دستور:

``` bash
mkdir
```

استفاده می‌کنیم.

مثال:

``` bash
(base) apm@APMs-MacBook-Pro desktop % mkdir new_folder
```

به جای `new_folder` می‌توانیم هر نامی که می‌خواهیم قرار دهیم.

------------------------------------------------------------------------

# خلاصه دستورات اولیه

-   `pwd` → نشان می‌دهد در کجا هستیم.
-   `cd` → ما را به مسیر دیگری می‌برد.
-   `mkdir` → یک Folder جدید می‌سازد.
-   `ls` → لیست فایل‌ها و Folder ها را نمایش می‌دهد.

------------------------------------------------------------------------

# Vim

`vim` فقط فایل ایجاد نمی‌کند، بلکه اجازه می‌دهد داخل فایل نیز بنویسیم و آن
را ویرایش کنیم.

ابتدا:

``` bash
touch l1.py
```

سپس:

``` bash
vim l1.py
```

اکنون می‌توانیم هر چیزی که می‌خواهیم داخل فایل بنویسیم.

بعد از پایان نوشتن:

ابتدا کلید:

    ESC

را می‌زنیم.

سپس:

    :wq

را نوشته و Enter می‌زنیم.

با این کار فایل ذخیره می‌شود و از Vim خارج می‌شویم.

------------------------------------------------------------------------

# مشاهده محتوای فایل با cat

برای مشاهده محتوای داخل فایل از:

``` bash
cat
```

استفاده می‌کنیم.

مثال:

``` bash
(base) apm@APMs-MacBook-Pro folder3 % vim l3.py

(base) apm@APMs-MacBook-Pro folder3 % ls
l1.py   l2.py   l3.py

(base) apm@APMs-MacBook-Pro folder3 % cat l1.py

(base) apm@APMs-MacBook-Pro folder3 % cat l2.py

(base) apm@APMs-MacBook-Pro folder3 % cat l3.py
print('salam')
```


# Summary

شما وارد Terminal در macOS، PowerShell یا CMD در Windows می‌شوید.

یک محیط متنی وجود دارد که به آن **Bash (Bourne Again Shell)** می‌گویند.

Bash یک درگاه ارتباطی است که به شما اجازه می‌دهد به صورت مستقیم با هسته
(Core) سیستم‌عامل و لپ‌تاپ صحبت کنید، بدون اینکه نیاز به GUI (رابط
گرافیکی) داشته باشید.

بسیاری از Server ها و بعضی از ابزارهای برنامه‌نویسی به همین شکل کار
می‌کنند.

# دستورات پایه

## مشاهده مسیر فعلی

برای فهمیدن اینکه در کجا قرار داریم:

``` bash
pwd
```

مثال:

``` text
/Users/apm
```

------------------------------------------------------------------------

## رفتن به یک Folder

``` bash
cd name
```

به Folder مورد نظر می‌رود.

مثال:

``` bash
cd desktop
```

------------------------------------------------------------------------

## برگشت به Folder قبلی

``` bash
cd ..
```

یک مرحله به عقب برمی‌گردد.

------------------------------------------------------------------------

## ساخت Folder

``` bash
mkdir name
```

یک Folder جدید ایجاد می‌کند.

مثال:

``` bash
mkdir project1
```

------------------------------------------------------------------------

## ورود به Folder

``` bash
cd name
```

مثال:

``` bash
cd project1
```

------------------------------------------------------------------------

## ساخت File جدید

``` bash
touch name.format
```

مثال:

``` bash
touch l1.py
```

یک فایل جدید ایجاد می‌کند.

------------------------------------------------------------------------

## ساخت و ویرایش File با Vim

``` bash
vim name.format
```

مثال:

``` bash
vim l1.py
```

با این دستور هم فایل ساخته می‌شود و هم می‌توان داخل آن کد نوشت.

برای نوشتن:

    i

برای ذخیره و خروج:

    ESC
    :wq
    Enter

------------------------------------------------------------------------

## نمایش فایل‌های داخل یک Folder

``` bash
ls
```

محتویات Folder فعلی را نمایش می‌دهد.

------------------------------------------------------------------------

## نمایش محتوای یک File

``` bash
cat file
```

مثال:

``` bash
cat l1.py
```

محتویات داخل فایل را نشان می‌دهد.

------------------------------------------------------------------------

## حذف File

``` bash
rm file
```

مثال:

``` bash
rm l1.py
```

یک فایل را حذف می‌کند.

------------------------------------------------------------------------

## حذف Folder

``` bash
rm -rf folder
```

مثال:

``` bash
rm -rf folder1
```

یک Folder به همراه تمام فایل‌های داخل آن را حذف می‌کند.

------------------------------------------------------------------------

# مثال عملی

یک Folder می‌سازیم، داخل آن یک فایل Python ایجاد می‌کنیم و با Vim داخل آن
کد می‌نویسیم.

``` bash
(base) apm@APMs-MacBook-Pro desktop % mkdir project1
(base) apm@APMs-MacBook-Pro desktop % pwd
/Users/apm/desktop
(base) apm@APMs-MacBook-Pro desktop % cd project1
(base) apm@APMs-MacBook-Pro project1 % touch l1.py
(base) apm@APMs-MacBook-Pro project1 % vim l1.py
(base) apm@APMs-MacBook-Pro project1 % ls
l1.py
(base) apm@APMs-MacBook-Pro project1 % cat l1.py
print('salam')

a=10
b=30
c = a + b
print(c)
```

# اجرای فایل Python از Terminal

برای اجرای فایل Python لازم نیست حتماً آن را داخل IDE یا Editor باز کنیم.

می‌توانیم مستقیم از Terminal اجرا کنیم:

``` bash
python3 l1.py
```

یعنی:

با Python3 فایل `l1.py` را اجرا کن.

خروجی:

``` bash
(base) apm@APMs-MacBook-Pro project1 % python3 l1.py
salam
40
```

------------------------------------------------------------------------

# ساخت محیط مجازی Python

برای ساخت محیط مجازی:

``` bash
python3 -m venv fanavari
```

به جای `fanavari` می‌توانید هر نامی که می‌خواهید برای محیط خود انتخاب
کنید.

مشاهده:

``` bash
(base) apm@APMs-MacBook-Pro project1 % ls
fanavari    l1.py
```

------------------------------------------------------------------------

# فعال کردن محیط مجازی

برای فعال کردن محیط:

``` bash
source fanavari/bin/activate
```

بعد از فعال شدن:

``` bash
(fanavari) (base) apm@APMs-MacBook-Pro project1 %
```

حالا می‌توانیم از کتابخانه‌های نصب شده در این محیط استفاده کنیم.

------------------------------------------------------------------------

# غیرفعال کردن محیط مجازی

برای خارج شدن از محیط:

``` bash
deactivate
```

مثال:

``` bash
(fanavari) (base) apm@APMs-MacBook-Pro project1 % deactivate
(base) apm@APMs-MacBook-Pro project1 %
```

------------------------------------------------------------------------

# Overview

# Overview

| Command | Example | چه کاری انجام می‌دهد؟ |
|---|---|---|
| `pwd` | `pwd` | نشان می‌دهد در چه مسیری قرار داریم |
| `cd` | `cd desktop` | وارد Folder مورد نظر می‌شود |
| `cd ..` | `cd ..` | یک مرحله به Folder قبلی برمی‌گردد |
| `ls` | `ls` | لیست تمام فایل‌ها و Folder های موجود در مسیر فعلی را نمایش می‌دهد |
| `mkdir` | `mkdir project1` | یک Folder جدید ایجاد می‌کند |
| `touch` | `touch l1.py` | یک فایل خالی جدید ایجاد می‌کند |
| `vim` | `vim l1.py` | یک فایل را باز یا ایجاد می‌کند و امکان نوشتن داخل آن را می‌دهد (`i` → نوشتن → `ESC` → `:wq` → Enter) |
| `cat` | `cat l1.py` | محتوای داخل یک فایل را نمایش می‌دهد |
| `rm` | `rm l1.py` | یک فایل را حذف می‌کند |
| `rm -rf` | `rm -rf folder1` | یک Folder به همراه تمام فایل‌های داخل آن را حذف می‌کند |
| `python3` | `python3 l1.py` | یک فایل Python را اجرا می‌کند |
| `python3 -m venv` | `python3 -m venv fanavari` | یک محیط مجازی Python ایجاد می‌کند |
| `source .../activate` | `source fanavari/bin/activate` | محیط مجازی را فعال می‌کند |
| `deactivate` | `deactivate` | محیط مجازی را غیرفعال می‌کند |
